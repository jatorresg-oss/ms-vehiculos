# Base de datos

Este microservicio trabaja con la base **logitrans_vehiculos**. Las bases de datos son
entregadas como insumo del ejercicio y no se versionan en el repositorio.

## Importación

1. Abrir phpMyAdmin o la consola de MySQL.
2. Importar el volcado correspondiente a `logitrans_vehiculos`.
3. Verificar que las tablas coincidan con los modelos de `app/Models`.
4. Copiar `.env.example` a `.env` y ajustar las credenciales si es necesario.
